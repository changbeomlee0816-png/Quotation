# 유호스트 견적 제작 프로그램

유호스트 견적 기준을 근거로, **업체명과 몇 가지 정보만 입력하면** 견적서가 자동으로 만들어지는
웹 프로그램입니다. 결과물은 **엑셀(.xlsx)** 과 **PDF** 두 가지로 내려받을 수 있습니다.

- 엑셀은 기존 견적서 양식(`갑지` / `상세내역` / `매출이익` 3시트)을 그대로 재현하며, 셀에 **수식이 살아 있어**
  엑셀에서 수량·단가를 고치면 합계가 다시 계산됩니다.
- PDF는 **페이지를 골라서** 받을 수 있습니다. (매출이익은 내부 자료라 기본으로 제외되어 있습니다.)
- 견적 기준(요금표·단가·요율)은 화면에서 직접 수정할 수 있고 브라우저에 저장됩니다.

---

## 실행 방법

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
```

배포용 정적 파일이 필요하면:

```bash
npm run build      # dist/ 생성
npm run preview    # 빌드 결과 확인
```

`dist/` 는 서버 없이도 동작하는 정적 파일이라, 사내 웹서버나 공유 폴더에 그대로 올려서 쓸 수 있습니다.
모든 계산과 파일 생성이 브라우저 안에서 이뤄지므로 견적 데이터가 외부로 나가지 않습니다.

### GitHub Pages 배포

`.github/workflows/deploy.yml` 이 기본 브랜치에 push 될 때마다 자동으로 빌드해서 Pages 에 올립니다.

처음 한 번만 저장소 설정이 필요합니다:
**Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꾸세요.
그 다음 push 하거나 **Actions** 탭에서 `Deploy to GitHub Pages` 를 수동 실행하면 됩니다.

주소: `https://changbeomlee0816-png.github.io/Quotation/`

> 이 주소는 **누구나 열 수 있습니다.** 그래서 원가를 소스에 넣지 않았습니다 —
> 아래 [원가 다루기](#원가-다루기)를 꼭 읽어 주세요.

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| **견적 정보** | 업체명·제목 등 갑지 정보와 Point / 계측기 / C/T / 모듈 / 게이트웨이 갯수 입력. 입력 즉시 기준이 적용됩니다. |
| **상세 항목** | 자동 생성된 줄을 확인·수정하고, 단가 카탈로그에서 항목을 추가합니다. 입력칸은 엑셀처럼 내용 길이에 맞춰 늘어나고, 입력 중 <kbd>Ctrl</kbd>+<kbd>Enter</kbd> 줄 추가, <kbd>Ctrl</kbd>+<kbd>D</kbd> 줄 복제, <kbd>Ctrl</kbd>+<kbd>-</kbd> 줄 삭제. |
| **견적 기준** | 클라우드 요금표, 자재비·시공 단가, 요율, 공급자 정보(직인), **거래처**, **단가 카탈로그**, 특기사항을 수정합니다. |

상단바에서 **견적 이력 · 견적 저장 · 내보내기 · 불러오기 · 새 견적**을 다룹니다.

- **견적 저장** — 지금 견적을 견적번호 기준으로 이 브라우저에 저장합니다. 같은 번호면 덮어씁니다.
- **견적 이력** — 저장한 견적을 검색해서 **열기 / 복제 / 삭제**합니다. 복제하면 새 견적번호와
  오늘 날짜로 사본이 만들어집니다.
- **견적번호**는 `YH-YYYYMMDD-NN` 으로 자동 채번되며 직접 고칠 수 있습니다.
- **할인**은 금액 또는 % 로 넣으면 갑지에 `소계 → 할인 → 합계` 로 표시되고, 절삭·부가세도
  할인 후 금액 기준으로 계산됩니다.

오른쪽은 A4 미리보기이고, 위쪽 막대에서 **엑셀 다운로드 / PDF 다운로드**와 **PDF 페이지 선택**을 합니다.
왼쪽 편집 영역과 미리보기 사이의 경계선을 **드래그하면 폭이 조절**됩니다 (더블클릭하면 기본값으로 복귀).
조절한 폭은 브라우저에 저장됩니다.

## 견적 기준

### 1) 클라우드 비용 — Point 갯수 기준 (1년)

| 구간 | 10P | 11~20P | 21~30P | 31~40P | 41~50P | 51~60P | 61~70P | 71~80P | 81~90P | 91~100P | 100P 이상 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 판매가 | 50만 | 100만 | 150만 | 200만 | 250만 | 300만 | 350만 | 400만 | 450만 | 500만 | 협의 |

- 입력한 Point 수가 속한 구간의 **연 금액 × 클라우드 년수**로 계상됩니다.
- `100P 이상`은 **협의** 구간이라 0원으로 들어가며, 상세 항목에서 직접 금액을 넣어야 합니다.
- 구간·금액·개수는 견적 기준 탭에서 추가/삭제/수정할 수 있습니다.

> **원가는 기본값이 비어 있습니다.** 아래 [원가 다루기](#원가-다루기)를 참고하세요.

### 2) 자재비 — 계측기 · 모듈 · 게이트웨이 (재료비)

| 구분 | 기본 규격 | 판매가 |
|---|---|---|
| 계측기 | ACCURA 2300S | 60만 |
| 모듈 | DO 모듈 | 20만 |
| 게이트웨이 | NDAS | 350만 |

- 갯수를 넣으면 **재료비**로 계상됩니다. 설치비는 여기 섞이지 않고 아래 3) 에서 따로 계산되어
  견적서에 **별도 줄**로 들어갑니다.
- 판매가 기본값은 기준 견적서(스마트분전반 ESG)에서 가져온 값이라 견적마다 고쳐 쓰면 됩니다.
  품명·규격·단위·비목도 전부 수정할 수 있고, 체크를 풀면 해당 항목이 생성되지 않습니다.

### 3) 시공비용 — 계측기 및 C/T 갯수 기준

| 구분 | 계측기 판매가 | C/T 판매가 |
|---|---|---|
| 설치비 | 30만 | 2만 |
| 네트워크 비용 | 35만 | — |

원가는 기본값이 비어 있습니다 — [원가 다루기](#원가-다루기) 참고.

- **계측기 네트워크 비용은 총갯수 +1** 로 계산합니다 (G/W 연결). 체크박스로 끌 수 있습니다.
- 각 항목을 재료비 / 노무비 / 경비 중 어느 비목으로 넣을지 고를 수 있습니다.
  (기본값: 설치비 → 노무비, 네트워크 → 경비, 클라우드 → 재료비)

기준표 예시(계측기 1, C/T 33)와 동일하게 나오는지 확인용 — 판매가 기준:

| | 계측기 | C/T | 계측기 비용 | C/T 비용 | 총 판매가 |
|---|---|---|---|---|---|
| 설치비 | 1 | 33 | 30만 | 66만 | 96만 |
| 네트워크 비용 | 2 | — | 70만 | — | 70만 |

### 4) 갑지 요율

| 항목 | 계산식 | 기본값 |
|---|---|---|
| 일반관리비 | (재료비 + 노무비 + 경비) × r | 6% |
| 안전 관리비 | (재료비 + 노무비) × r | 3% |
| 이윤 | (노무비 + 경비 + 일반관리비) × r | 10% |
| 부가세 | 합계 × r | 10% |
| 합계 절삭 | `ROUNDDOWN(합계, n)` | 십만원 미만 절삭 |

## 거래처 · 단가 카탈로그

**거래처** (`견적 기준 → 6) 거래처`) — 업체명·참조(담당자)·연락처·이메일·메모를 등록해 두면,
`견적 정보` 탭의 업체명 칸에서 **자동완성**으로 고를 수 있고 참조까지 함께 채워집니다.
견적 작성 중에 업체명·참조를 넣고 **거래처 저장** 을 눌러도 목록에 추가됩니다
(이미 있는 업체면 참조만 갱신).

**단가 카탈로그** (`견적 기준 → 7) 단가 카탈로그`) — `상세 항목` 탭의 **+ 단가표에서 추가**
목록입니다. 분류·품명·규격·단위·재료비·노무비·경비·원가를 직접 추가/수정/삭제할 수 있고,
분류 필터와 검색으로 찾습니다. 기본값은 기준 견적서에서 뽑은 37개 품목입니다.

둘 다 브라우저에 저장되고 **기준·견적 저장** JSON 에 함께 담깁니다.

## 원가 다루기

**이 저장소는 공개(public)이고, 빌드 결과도 공개 주소로 배포됩니다.**
그래서 원가는 소스에 넣지 않습니다 — 넣으면 판매가와 나란히 놓여 마진 구조가 그대로 드러납니다.
모든 원가 기본값은 `0` 이고, 실제 원가는 각자 브라우저에만 있습니다.

처음 한 번만 이렇게 설정하면 됩니다.

1. **견적 기준** 탭에서 원가 칸을 채웁니다 (클라우드 구간별 원가, 설치비·네트워크 원가).
2. 상단 **기준·견적 저장** 을 눌러 JSON 파일을 받습니다.
3. 그 JSON 은 **사내에서만** 보관합니다 — 저장소에 커밋하거나 외부에 올리지 마세요.
4. 다른 PC 나 팀원은 상단 **불러오기** 로 그 JSON 을 열면 원가까지 그대로 복원됩니다.

**직인 이미지도 같은 이유로 소스에 넣지 않습니다.** `견적 기준 → 5) 공급자 정보` 에서 직인을
올리면 220px PNG 로 줄여 브라우저에 저장되고, 갑지의 대표이사 이름 옆에 찍힙니다
(PDF·엑셀 모두 반영). 이 이미지도 위 JSON 에 함께 담기니 사내에서만 보관하세요.

한번 입력하면 브라우저(localStorage)에 남아 있어서 매번 불러올 필요는 없습니다.
원가가 비어 있는 동안에는 견적 기준 탭 상단에 경고가 뜨고, 매출이익 시트의 이익률이 100% 로 나옵니다.
고객에게 나가는 **갑지와 상세내역은 원가와 무관하므로** 원가를 안 넣어도 정상적으로 쓸 수 있습니다.

## 자동 생성과 직접 수정

Point·계측기·C/T·모듈·게이트웨이 갯수를 바꾸면 해당 줄이 기준에 맞춰 다시 만들어집니다.
자동 생성된 줄에는 `자동` 표시가 붙습니다.

그 줄을 **직접 고치면 자물쇠(🔒)로 바뀌고, 이후 재계산에서 덮어쓰지 않습니다.**
원래대로 되돌리려면 그 줄을 지우고 `견적 기준 다시 적용`을 누르면 됩니다.

견적 기준 탭에서 단가를 바꾼 경우에는 자동 반영되지 않습니다 — 작성 중인 항목이 리셋되면 곤란하므로,
`견적 정보` 탭의 **견적 기준 다시 적용** 버튼을 눌러 반영합니다.

## 출력물

### 엑셀 (.xlsx)

기존 양식과 같은 3개 시트로 나옵니다.

- **갑지** — 수신/제목 등 머리글, 한글 금액 표기, 재료비·노무비·경비 + 일반관리비·안전관리비·이윤,
  `ROUNDDOWN` 합계. 단가 칸은 `상세내역` 총계를 참조하는 수식입니다.
- **상세내역** — 그룹별 소계와 총 합계. 소계는 `SUM`, 합계는 `F+H+J` 수식.
- **매출이익** — 위와 같은 표에 원가·매출이익·이익률이 붙고, 아래에 갑지 요율(일반관리비/안전관리비/이윤)을
  더한 최종 합계가 나옵니다.

한글 금액은 엑셀 전용 함수 `NUMBERSTRING` 대신 미리 계산한 문자열로 넣습니다.
(해당 함수는 일부 환경에서 `#NAME?` 가 되기 때문입니다.)

### PDF

미리보기의 각 A4 페이지를 그대로 그려서 담습니다. 상단 막대의 **PDF 페이지** 체크박스로 넣을 페이지를 고릅니다.
상세내역이 길면 여러 장으로 자동 분할되고, 각 장을 따로 선택할 수 있습니다.

## 견적 저장 / 불러오기

상단 **기준·견적 저장** 버튼으로 견적 기준과 작성 중인 견적을 JSON 한 파일로 내려받고,
**불러오기** 로 그대로 복원합니다. 기준을 팀에 공유하거나 지난 견적을 다시 열 때 쓰면 됩니다.
평소 작업 내용은 브라우저(localStorage)에도 자동 저장됩니다.

## 기술 구성

정적 SPA 하나로, 서버가 필요 없습니다.

| | |
|---|---|
| 빌드 | Vite + React + TypeScript |
| 엑셀 | ExcelJS (셀 서식·병합·수식을 브라우저에서 직접 작성) |
| PDF | html2canvas-pro 로 A4 페이지를 캔버스에 그린 뒤 jsPDF 로 합침 |

PDF를 이미지로 그리는 이유는 한글 폰트를 PDF에 심지 않고도 글꼴이 깨지지 않게 하기 위해서입니다.

```
src/
├── types.ts                 데이터 모델 (견적 기준, 항목, 입력값)
├── defaults.ts              유호스트 기본 기준값 + 단가 카탈로그
├── calc.ts                  산출 엔진 (요율, 자동 항목 생성, 한글 금액)
├── pages.ts                 A4 페이지 분할
├── store.ts                 localStorage 저장 / JSON 내보내기
├── export/excel.ts          3시트 엑셀 생성
├── export/pdf.ts            페이지 선택 PDF 생성
└── components/              QuoteForm · ItemsEditor · StandardsEditor · Preview
```
